# Design Philosophy

This application adopts a "professional utility" aesthetic inspired by tools like Linear and Vercel. 
It replaces gamified/childish patterns with a serious, execution-oriented interface aimed at teenagers treating their homework like professional projects.

## Visual Language
- **Typography:** Inter (Sans) and Geist Mono for data/metrics. Strong hierarchy, tight tracking on headings.
- **Palette:** Sleek dark mode (Deep blacks and grays: `#0A0A0A`, `#171717`, `#262626`) with very high contrast text. Accents are Indigo (`#4F46E5`) and Green (`#10B981`).
- **Layout:** Generous spacing, subtle borders, no heavy shadows. 
- **Gamification:** Reduced to sophisticated metrics (Streak dots, raw XP values) in the header. No mascots.
- **Forms:** Floating labels, borderless inputs, keyboard-first aesthetic.

## Key Screens
1. **Landing Page:** Features a massive glowing text header and bento-box features layout, positioning the app as a high-end tool.
2. **Dashboard (Home):** Built like an issue tracker. Tasks are "Issues" with ID prefixes (e.g., MA-1234), tags, and mono-spaced dates.
3. **Validation (ConcluirDever):** A clean upload area that focuses on the utility of submitting proof.
